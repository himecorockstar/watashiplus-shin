ふわナースの使い方

入院中の大学生が、一日使う例です。全部の機能を覚える必要はありません。まずは「体調と測定データ」「日記帳」「ボイスメモ」の３つから始めましょう。

表紙は最初の画面です。「戻る」で１つ前へ、「表紙へ」で最初の画面へ戻れます。困ったら「説明」を押すと、その画面の使い方が出ます。説明を閉じ、説明をOFFにすると普通に操作できます。

朝７時：起きたら、今の体調を残す

  1. 表紙の「体調と測定データ」を押します。
  2. 「体調を記録する」を押します。
  3. 当てはまる症状を選びます。痛みは０（痛くない）～５（最も強い痛み）です。気分や睡眠など、分かる項目だけで大丈夫です。
  4. 「体調を保存」を押し、保存できた表示を確認します。
  5. 「戻る」で前の画面へ戻ります。

体温などの測定値があれば、「測定値とグラフ」の「データ記録・変更」から入力して保存します。薄い数字は前回の値です。今回の値を確認し、保存する項目にチェックを付けます。日付を変えれば、昨日の記録も後から入れられます。

朝８時：薬を飲んだことを記録する

  1. 表紙の「すべての機能を開く」から「お薬の記録」を選びます。
  2. 薬名・量・単位などを、薬の説明書や病院の指示を見ながら登録します。難しければ登録は手伝ってもらってください。
  3. 実際に飲んだ後に、該当する薬や食後のグループを選び、内容を確認して服用を記録します。

飲んだか分からないときは「飲んだか不明」を使います。アプリの記録だけで、もう一度飲むかを決めず、看護師さんなどに確認してください。残量は実物に合わせて自分で更新します。

午前10時：先生に聞きたいことをメモする

  1. 「すべての機能を開く」から「先生・看護師さんに聞くこと」を押します。
  2. 聞きたいことを短く書き、「追加して保存」を押します。
  3. 聞けた項目にはチェックを付けます。

診察の前には「診察で見せる記録」を開き、期間と見せる項目を選びます。画面の内容を自分で確認してから見せます。日記の本文や写真は自動では入りません。

昼12時：一言の日記と写真を残す

  1. 表紙の「日記帳」→「日記を書く」を押します。
  2. 白い欄に「昼ごはんがおいしかった」など、好きなことを書きます。
  3. 写真を付けたいときは写真の選択欄を押します。「ファイル・クラウドから写真を選ぶ」も使えます。
  4. 「保存」を押し、保存できた表示を確認して戻ります。

写真を付けず、文字だけでも使えます。体調は「体調と測定データ」にまとめます。以前の日記は「編集」で直せます。「内容検索」では、覚えている言葉の一部分や日付から探せます。クラウドにある写真を選べるかは、スマホの設定によります。

午後３時：書く代わりに、声でメモする

  1. 表紙の「ボイスアラーム・ボイスメモ」を押します。
  2. 「ボイスメモを録音」→「録音」を押します。初めてマイクの許可を聞かれたら「許可」を選びます。
  3. 話し終わったら「停止」を押します。１件最長20秒です。
  4. 自動保存できた表示を確認します。「聞く」で録った声を確認し、「戻る」を押します。

文字は何も書かなくて大丈夫です。録音した日時が秒まで自動で残ります。後で日付から探して「再生」を押せます。録音や保存に失敗した表示が出たら、保存済みと考えず、その画面の案内を確認してください。

午後４時：予定を声で知らせる設定をする

  1. 「ボイスアラーム・ボイスメモ」→「ボイスアラームを追加」を押します。
  2. 新しく作るときは現在の時刻が出ます。時・分のダイヤルを上下になぞって、知らせたい時刻に変えます。日付も確認してください。
  3. 「約束の時間です」などの文を押すか、「読み上げる内容」に自由に書きます。選択した文の後にも書き足せます。
  4. 必要なら繰り返しを選びます。入力後の「自動保存しました」を確認して戻ります。
  5. 一覧の「アラームを有効にする（音を確認）」を押します。「試し聞き」で内容と音量を確認します。

文字は上から続けて１回読みます。録音した場合はその声、ブザー・ベルを選んだ場合はその音になります。音を止めたいときは「読み上げ・音を止める」を押します。

アラームは、このアプリを表示している間の補助機能です（他のページでも時刻を確認します）。画面をロックしたり、他のアプリへ移ったりすると、予定時刻に鳴る保証はありません。大切な予定はスマホ本体のアラームも設定してください。

夕方６時：少し休む

「すべての機能を開く」から、ミニゲーム、写真立て、自然音、手鏡を選べます。ゲームのヒントは各ゲーム内にあります。手鏡は表紙の看板を１秒長押しでも開けます。手鏡の「終了」を押すとカメラが止まります。

自然音は好きな季節と時間帯を選んで再生します。停止ボタンで止められます。音量と周囲への配慮を忘れずに。

夜９時：一日を残して終わる

  1. 体調の変化があれば、「体調と測定データ」に追加します。
  2. 「日記帳」に今日のことを一言だけでも書いて保存します。
  3. 録音などの処理が終わり、保存できた表示を確認してから画面を閉じます。

毎日すべてを埋めなくても大丈夫です。残したいことだけ、無理のない範囲で使ってください。

大切な記録を守る

  1. ときどき「バックアップ・機種変更」を開きます。
  2. 「バックアップを書き出す」を押します。
  3. 保存できたファイルを、スマホ以外の自分の保管先にも残します。難しければ、信頼できる人に保存を手伝ってもらってください。

スマホを替えても、記録は自動では引き継がれません。新しいスマホでバックアップを読み込み、記録を確認するまで、古いスマホの記録を消さないでください。バックアップには日記・写真・録音などが入るので、渡す相手に注意してください。

「ごみ箱へ」に移したものは、ごみ箱から戻せます。「完全削除」は取り消せません。ブラウザーのデータ削除は、アプリ内の記録を失う原因になります。

その他：LAST CALL

飲酒記録は「LAST CALL」を開くと、見出しのすぐ下に操作手順が表示されます。商品・度数・量を自分で確認して記録する機能です。

言葉・観察・状況推理のゲームとクイズ

「ミニゲーム50」は言葉・観察・状況推理の47テーマと、絵合わせ・消灯・迷路です。計算や数字の答えを求めるゲームを入れ替えました。テーマを開き、本文を読んで言葉の答えを選びます。各テーマ３問を順不同で出し、一巡までは重複しません。クイズと問題を一部共有します。盤面は広い画面で操作できます。ゲームの一覧へ戻る操作と表紙へ戻る操作は、移動先が異なる場合に両方表示します。

「推理クイズ150」では、簡単・普通・難しいを選びます。各50問をランダムな順番で出し、一巡するまでは同じ問題を出しません。全問、答えは数字ではなく言葉です。問題文は平均約90文字、最長800文字以内。言葉遊び、観察、舞台、旅館、手紙、証言など多ジャンルです。各コースに少し長い推理短編を３問含みます。答えを選ぶと理由を読めます。「次の問題」で進みます。コースを選び直すと、新しい順番で最初から始まります。

追加：アラームの期限

１回だけのアラームは、設定時刻の24時間後に一覧から削除し、ごみ箱へ移動します。閉じている間に期限が来た場合は、次に開いた時に処理します。繰り返しと録音メモはこの自動削除の対象外です。時刻を５分以上過ぎてから復帰したアラームは、遅れて鳴らさない仕様です。

読み上げる内容の入力欄

ボイスアラームの「読み上げる内容」は、約30文字が見える小さな欄にしました。これは文字数の上限ではありません。長い文も入力でき、欄の中を上下に動かして確認できます。自動保存と、全文を続けて読む動作はそのままです。

新しい表紙と画面

表紙の「いつもの記録」から、日記帳・体調と測定データ・ボイスアラームとボイスメモを開けます。「すべての機能」を押すと、「記録と暮らし」「ひと息の時間」「道具と設定」が開きます。機能は減らしていません。

見出し・説明・入力欄・操作ボタンを、葡萄色と生成りの共通デザインに整えました。説明は「？」、表紙へ戻る操作は淡い金色の「表紙へ」を使います。下部の「保存とご利用について」を押すと、記録の保存に関する説明が開きます。

表示設定の「暗い画面」「文字を大きく」は引き続き使えます。表紙の項目順は、各グループの中で反映します。看板を１秒長押しする手鏡も引き続き使えます。
