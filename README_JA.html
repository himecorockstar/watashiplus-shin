ふわナース ひめころさん版 ver1.08
2026年10月31日

今回の変更
・表紙最上部を大きな葡萄の看板へ変更。旧マークを削除。名称は「ふわナース」。
・「体調と測定データ」に体調記録と測定・グラフを統合。独立した体調記録の入口は削除。
・日記は自由な文章と写真。体調項目は日記に重複表示しません。
・過去の日記内の体調値も残し、体調側から確認・変更できます。診察用まとめに私的な日記本文を混ぜません。
・写真選択に「ファイル・クラウドから写真を選ぶ」を追加。日記・写真立て・持主写真で使用できます。
・ボイスメモは入力不要。録音→停止で自動保存。録音日時を年月日・時分秒で自動記録し、日付で探して再生できます。
・録音時間も表示。１件の録音上限は従来どおり20秒です。
・アラーム編集の見出し直下に６種類のボタンを追加。
  おはようございます／出かける時間です／約束の時間です／お薬の時間です／やかましいブザー／やかましいベル
・選択時に文言を入力。ブザーとベルは異なる合成音で試聴・時刻通知します（約５秒）。音の停止ボタンあり。
・種別を選び直すと以前の録音は解除されます。選択後に録音すると録った声へ切り替わります。

記録を残すために
・ver1.07と同じ保存領域とバックアップ形式を維持しています。更新のためにブラウザーのデータを消さないでください。
・旧版の録音には秒単位の日時が保存されていないものがあります。その場合「秒の記録なし」と表示します。秒を推定して補いません。
・秦さん版の保存領域と公開先は変更しません。
・GitHubのアカウントやホストが変わると端末内の記録は自動では移りません。先に旧版でバックアップを保存して新しい場所へ読み込んでください。
・読み込みは現在の記録を置き換えます。先に現在のバックアップも保存してください。

制限・未確認
・アラームはこの画面を開いている間の補助機能。自動音声の有効化が必要です。ロック中、別アプリ中、ブラウザー終了中の確実な通知は保証できません。
・ブザー／ベルの音量は端末設定に依存し、消音は強制解除できません。
・クラウド選択は端末のファイル画面に表示されるサービスが対象。必要ならサービスのアプリや設定を先に用意してください。写真の読み込みには通信が必要になることがあります。
・画像形式によって読み込めない場合はJPEGなどへ変換してください。
・今回の環境では検証用ブラウザーを導入できず、実際の画面操作は未確認です。Android/iPhoneでの実音録音・クラウド選択・音の聞き取りも未確認です。

確認した内容
・JavaScript構文、簡易DOMでの初期化、表紙参照、体調統合、旧体調値の保持、日記への重複表示防止。
・画面別説明、６種類の文言反映、疑似音声装置でのブザー／ベルの音生成スケジュール。
・文字なし録音メモの保存、秒単位の日時と録音時間、日付検索、重複登録防止。
・ボイスメモを時刻通知から除外。アラームの時刻判定と同日の二重通知防止。
・バックアップに録音日時を保持。ZIP破損検査、JS参照一致、音源12件、表紙の透過を確認。
・処理試験は実機での録音や画面操作試験の代わりにはなりません。
