ふわナース ひめころさん版 ver1.11
2026年10月31日

今回の変更
【ボイスアラーム】
・アラーム一覧だけでなく、アプリ内の他の画面を表示中も時刻を確認します。編集画面にいても、録音処理中でなければ確認します。
・同じ１分を逃すと鳴らない処理を改め、予定時刻から５分以内の復帰なら補助通知します。５分を超えたものを遅れて鳴らすことはしません。
・「アラームを有効にする（音を確認）」ボタンを追加。最初に押して、声が聞こえるか確認してください。
・録音・ブザー・ベル・本文の自動通知で、音の開始が確認できてから「通知済み」にします。開始失敗時は画面に案内し、５分以内の範囲で10秒間隔の再試行を行います。
・同じ日に通知済み・済んだ状態だった予定も、時刻や内容を変更すると通知用の状態を更新します。
・新しく登録・変更したアラームほど上に表示します。通知しただけで並び順は変えません。
・１回だけのアラームは、設定時刻の24時間後に一覧から自動削除し、ごみ箱へ移動します。録音もその記録内に残り、完全削除しない限り戻せます。
・繰り返し設定とボイスメモは自動削除しません。閉じていた間の期限処理は次の起動時に行います。編集中の録音メモがある場合は閉じてから期限処理します。
・時・分は、全数字を並べる選択から、上下になぞるダイヤルへ変更。▲▼・マウスホイール・キーボードの上下でも変更できます。
・新規は現在時刻から開始し、既存の日時は保持。時刻変更後の自動保存表示を確認してください。

【移動ボタン】
・同じ行き先になる場合は「表紙へ」を優先し、「戻る」を省略します。
・表紙ボタンの重複を整理し、左上を優先。右下の重複ボタンは削除。
・ゲーム一覧へ戻る等、表紙とは異なる行き先の「戻る」は維持します。
・「表紙に戻りました」の通知を削除。

【ゲーム・クイズ】
・ミニゲームを30種類から50種類へ追加。新しい20種類は、数独の穴埋め、２列の規則、目標の合計、鏡の図形、重り、ドミノ、経路、暗証番号、回転等の思考問題です。
・各ゲームの専用の短い遊び方を、ゲーム画面に表示。説明モードでもゲーム別の説明を使います。
・ゲームと推理クイズの画面を、ブラウザーの表示領域いっぱいに拡大。盤面や選択ボタンも拡大。
・推理クイズを、簡単50問・普通50問・難しい50問、計150問で追加。
・簡単にはトンチ・駄洒落・文字遊びを含め、難しいコースは暗証番号・並び順・発言・経路・組合せ等の推理を中心にしました。
・コース内の50問をランダムな順番で出し、一巡するまでは同じ問題を出しません。
・コースを選び直すと再抽選します。ゲームやクイズの途中経過は再読み込みすると最初からです。
・解答後に答えと理由を表示。制限時間はありません。

確認した内容
・JavaScript構文、アラームの全ページ判定、５分以内の復帰、音失敗時の再試行、成功前に通知済みにしない処理、同日再設定。
・疑似音声装置による、開始・終了・取消の処理。スマホから実音を出した試験ではありません。
・24時間後のごみ箱移動、繰り返し・ボイスメモ・録音データの保持、通知の二重処理防止。
・新しい順の並び、ダイヤルの端の循環と保存、ナビゲーションの優先と重複整理、ゲーム全画面CSS。
・新ゲーム20種類について計2000回の問題生成を確認。50種類で50本の異なる説明を用意。
・クイズ各50問、選択肢の重複がないこと、一巡までの問題重複防止を確認。
・難しい50問は、条件の候補全列挙、暗証番号・割り算・重さ・組合せの一意性、経路・作業順・スイッチの最小値を検証。
・前版の飲酒記録、集計、取消、商品追加、バックアップ、旧痛み値、録音日時等も確認。
・ZIP CRC、実行JS一致、参照先、音源12件、クイズ150問。

未確認・制限
・実際のブラウザー画面操作、スマホでの時刻待ち自動通知、ダイヤル操作、全画面表示の実機確認は未実施です。検証用ブラウザーを利用できないため、処理試験と実機動作を区別しています。
・スマホでまず「アラームを有効にする（音を確認）」を押し、１～２分後に設定して、アプリを表示したまま通知を確認してください。
・画面ロック中、他のアプリ使用中、ブラウザー終了中に確実に通知する機能ではありません。OS本体のアラームも併用してください。
・ブラウザーが音声の自動再生を拒否する場合、画面の案内に従い、音を確認するボタンを押してください。端末の消音や音量は強制変更しません。
・録音・処理中は録音への干渉を避けて通知を待ち、５分以内なら処理後に確認します。
・ブラウザーの操作バーを消せるかは端末によります。
・既存ゲーム30種類を、スマホ実機ですべて再試験したわけではありません。
