今回の変更
・新規の測定値は白紙。入力した項目だけまとめて保存します。
・過去の編集は、その記録の値だけを表示し、同じ記録を更新します。
・入力欄には「タップして入力」、記入例は欄の外へ表示します。
・服薬記録の新規日時・状態は白紙。明示的な操作で入力します。
・家族への依頼のボタンとメニューを撤去。保存済み記録は内容検索に残します。
・質問メモの編集時に分類が消える不具合を修正しました。
・使い方、ゲーム、クイズなど、前画面があるところに戻る操作を用意しました。
・ゲーム50種類に、操作説明、目標、一手戻る、戻した手を進める、ヒント、初期盤面のやり直し、盤面を変えない操作例を追加しました。
・クイズ150問は各コース、自己確認33問・二択9問・四択8問。答え本文は30文字以内、解説は別表示。前の問題へ戻っても確認状態を保持します。
・電話帳に編集ボタン、女性用の記録に入力項目の選択ボタンを追加しました。
・並べ替えは分類ごとに行い、分類の境界で効かないボタンをなくしました。
・使い方を現在の画面に合わせて更新しました。

戻るボタンを追加しない場所
表紙の最上位（前画面なし）、５分類の開閉部分（その場で開閉）、写真・手鏡（既存の戻る・終了を利用）。新しい操作用ページは増やしていません。

更新方法
１．このZIPを展開します。
２．github-pagesフォルダー内のファイル・フォルダーを、現在と同じGitHub Pagesの公開場所へ反映します。
３．スマホで同じURLを開き直し、画面下のver1.18を確認します。
４．古い表示のままなら、ページを一度閉じて開き直してください。ブラウザーのデータを消すと保存記録も失われるので、更新のためにデータ削除はしないでください。

既存の記録保存先・データ形式を継続しています。公開・アップロードは行っていません。
音源12種類と既存画像を同梱。ライセンス・出典はgithub-pages内のAUDIO_CREDITS.txt、LAST_CALL_SOURCES.htmlを参照してください。

プログラム上で保存・入力・クイズ・50ゲームの動作例と構造を確認しました。スマホ実機の表示、タッチ操作、実際の音声、ロック中の通知は未確認です。
アラームは画面表示中の補助機能であり、ロック中や他アプリ使用中の確実な通知はできません。
