ふわナース ひめころさん版 ver1.10
2026年10月31日

今回の変更
・新規アラームの初期時刻を現在の時刻へ変更。既存アラームの編集は保存済みの日時を維持。
・時刻は「時」「分」を押して選ぶ方式に変更。端末標準の時刻入力に依存せず、変更した時刻を自動保存します。
・「現在の日付・時刻に合わせる」ボタンも用意。日付も同時に現在へ変更されます。
・アラームと録音メモの編集画面をブラウザー表示領域いっぱいに拡大。背景を不透明にし、下の画面が透けない構成へ変更。
・同じ働きの「閉じる」「戻る」を整理し、戻る操作を統一。表紙へ戻る操作は別に残します。
・入れ子の編集画面では「戻る」と「編集を閉じて一覧へ」が異なる移動をするため、区別して表示します。
・LAST CALLの見出し直下に、初めて使う人向けの手順を追加。
・「使い方（入院中の一日）」を追加。スマホが苦手な大学生を想定し、朝の体調記録、服薬履歴、質問、日記・写真、録音、アラーム、夜の記録、バックアップまで順に説明。
・ゲームの細かなルールは使い方案内に含めていません。

使い方を見る
アプリの表紙→「すべての機能を開く」→「使い方（入院中の一日）」を押します。
同じ案内を、このZIP内の「ふわナースの使い方.txt」、またはgithub-pages内のFUWA_GUIDE.htmlでも読めます。

更新と記録
ver1.07～1.09と同じ保存領域とバックアップ形式を維持しています。
更新するためにブラウザーのデータを削除しないでください。
公開先のホストを変更する場合は、前の場所でバックアップを書き出し、新しい場所で読み込んでください。
読み込みは現在の記録を置き換えます。先に現在のバックアップも保存してください。
LAST CALLの商品一覧・飲酒記録、日記・写真・録音、旧0～10の痛みなどは保持する構成です。

確認した内容
・JavaScript構文、初期化、時刻欄の生成、時・分の変更と保存、範囲外時刻の拒否。
・新規画面は現在時刻、既存画面は保存済み日時を維持する処理。
・通常と入れ子の画面で、同じ働きのナビゲーションを重複させない処理。
・LAST CALLの説明位置、使い方案内と表紙からの入口。
・前版の主要試験も実施：飲酒記録・集計・取消・商品追加・バックアップ、旧痛み値の保持、本文読み上げ、録音日時など。
・ZIP破損検査、参照ファイル、実行JSの一致、音源12件。
これらは簡易DOM等を使う処理試験です。実際のブラウザー画面操作の確認とは区別しています。

未確認・制限
・今回も検証用ブラウザーを利用できず、実際の画面表示とスマホでのタッチ操作は未確認です。
・Android/iPhoneで、アラーム時刻を変更して開き直した時に保持されるか、編集画面が表示領域を覆うかを確認してください。
・鏡の実表示、実音録音、長文の実際の読み上げ、ブザー・ベル、クラウド写真選択も実機未確認です。
・画面をロックした時、他のアプリを使っている時、ブラウザー終了中の確実なアラームは保証できません。
・予定時刻の補助通知は、自動音声を有効にし、アラーム一覧を開いて使います。重要な予定はスマホ本体のアラームも併用してください。
・OSやブラウザーの操作バーは端末によって残ります。

GitHubへのアップロード
1. このZIPをダウンロードし、右クリック「すべて展開」を選びます。
2. github-pagesフォルダーを開きます。
3. ひめころさん版リポジトリの「Add file」→「Upload files」を開きます。
4. github-pagesフォルダーの中身をすべてアップロードします。
5. 「Commit changes」で保存し、公開ページを再読み込みして最下部のver1.10を確認します。
秦さん版の公開先へはアップロードしないでください。
古いJSファイルが残っていても、今回のindex.htmlはapp-v1.10.jsを読みます。記録やブラウザーデータを消して更新しないでください。
