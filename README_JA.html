ふわナース ひめころさん版 ver1.23
2026年11月2日

今回の改造
・常識クイズを300問から1,600問へ増量しました。ペット・料理・運動・スマホ・配信・家電・キャバクラ・お酒の８ジャンル各200問です。
・各ジャンルは200問をランダム順に出し、一巡までは同じ設問を繰り返しません。前の問題へ戻っても、その回の答え確認状態を保ちます。コースを選び直すと進行はリセットします。
・追加1,300問は、考えてから答えを開く形式です。答え本文は30文字以内、解説は別に開きます。元の二択問題も残しました。接客などの場面問題には、適切な対応例を答えとするものがあります。
・「大切な記録は定期的にバックアップ」を赤い横長一列のラベルにし、画面最下部に常時表示します。クイズ・ゲーム・写真立て・手鏡でも表示します。
・「ひと息・遊び」の末尾に、少し目立つ「ふわっち」への入口を追加しました。外部サイトを別のタブで開き、元のタブへ戻るとこのアプリを続けられます。
・明るい室内での手鏡を想定し、前面カメラの高解像度を優先します。対応上限を取得できる場合は、その値を目標にします。映像の下部に実際の幅×高さを表示します。

鏡について
アプリから高解像度を希望しても、機種・ブラウザが提供する映像が上限です。必ずカメラの全画素を利用できる保証はありません。設定が未対応でも、可能なら通常のカメラ表示へ戻します。撮影映像は保存・外部送信しません。スマホ実機での画質は未確認です。

継続する機能
ゲーム50種類、写真10枚と10秒のランダム切替、LAST CALL、日記・体調・女性用記録・お薬・ボイスメモ・アラーム、金色プレート・時計などを維持しています。
保存データの名前・形式は変更していません。更新前のバックアップをおすすめします。

更新方法
1. ZIPを展開します。
2. github-pagesフォルダーの中身を、これまでと同じGitHub Pages公開先へアップロードします。
3. 同じ公開URLを開き直し、最下部のバージョンがver1.23になったか確認します。
4. 古い表示が残る場合は一度ページを再読み込みします。ブラウザのサイトデータは消さないでください。
※ZIPを解凍しただけでは公開サイトは更新されません。

問題と資料
「クイズ1600問と解説.txt」に全問を収録しています。アプリの「問題について・参考資料」から参照資料を確認できます。問題文・解答・解説は独自作成で、既存問題集の転載ではありません。各資料の提供者による監修を意味しません。

これまでの制約
画面を閉じた状態・ロック中のアラーム動作は保証できません。録音は１件最長20秒。新しいクイズや一部画面は日本語中心です。端末上の許可・カメラ・音声・クラウド選択の実機確認が必要です。
