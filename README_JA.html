Watashi Plus ひめころさん版 ver1.07（2026年10月31日）

変更点
・説明ONで現在のページに合う簡潔な説明を表示。各機能の長押し説明も対応。
・日記帳は自由な本文と写真。内容検索を用意。
・気分、便通、睡眠、だるさを体調記録へ統合。日付指定、過去の変更に対応。
・ボイスアラームと録音だけのボイスメモを分離。録音は最長20秒、停止後自動保存。
・ボイスメモは時刻通知しません。

重要
・秦さん版と別の保存領域を使用し、秦さん版の記録は削除しません。
・以前の記録をこちらでも使う場合、旧版でバックアップを書き出してから、この版で読み込んでください。
・読み込みはこの版の現在の記録を置き換えます。先にこの版のバックアップも保存してください。
・アラームはこの画面を開いている間の補助機能です。画面ロック中などの確実な通知は保証できません。
・Android/iPhoneでの実音録音と再生は未確認です。
・今回の実行環境にブラウザーがなく、画面操作の自動確認は未実施です。

配置
新しいGitHubリポジトリにgithub-pagesフォルダーの中身をアップロードしてください。
秦さん版の公開先へはアップロードしないでください。
音源の利用条件はgithub-pages/AUDIO_CREDITS.txtを維持してください。

検証
JavaScript構文、簡易DOMを使う初期化、日記と体調の分類、ページ別説明、
ボイスメモのアラーム対象除外、音声一覧の生成を確認しました。
これはブラウザーの画面検証や実音の録音試験を代替しません。
