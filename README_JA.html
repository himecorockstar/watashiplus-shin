ふわナース ひめころさん版 ver1.12
2026年11月1日

今回、保留していた変更を実装しました。

【読み上げる内容】
・ボイスアラームの入力欄を、約30文字が見える小さな２行の欄へ縮小しました。
・表示の大きさだけの変更で、30文字の入力制限ではありません。長文も入力・保存・全文読み上げできます。
・長い文は入力欄の中を上下へ動かして確認できます。自動保存のタイミングは変更していません。

【クイズ】
・数字中心だった問題を、言葉・観察・状況推理中心の創作150問へ全て置き換えました。
・簡単50問、普通50問、難しい50問。全問、答えは言葉です。数字の読み替えでごまかしていません。
・雪の庭、証言、手紙、喫茶店、図書室、舞台、旅館、動物、料理、駅、雨、鏡、しりとり、駄洒落、言葉の並べ替え、看板、忘れ物、贈り物、伝言など。
・各コース内はランダムな順番で、一巡まで同じ問題を出しません。答えと理由を表示します。
・通常の短い問題141問に、少し長い推理短編９問（各コース３問）を混ぜました。
・実際の問題文の平均86.5文字、最長297文字。上限800文字以内で、平均100文字程度という要望に合わせ短めにしました。
・短編も説明のための手掛かりを本文に入れ、後出し設定による正解にはしていません。
・難しいコースには視点の転換、証言の矛盾、条件の組合せ、決められないと見抜く問題等を含みます。
・「情報不足」「条件の矛盾」が正解になる問題もあります。
・難易度は今回の編集上の分類です。利用者による難易度評価はまだ行っていません。

【ゲーム】
・数学や数字の答えを求めるゲームを入れ替えました。
・言葉・観察・状況推理の47テーマに、数字の答えが不要な絵合わせ・消灯・迷路の盤面３種を合わせ、50種類です。
・各テーマは３問を順不同で出し、一巡までは重複しません。問題は推理クイズと一部共有します。
・テーマごとの遊び方、４つの言葉からの選択、ヒント、解説、もう一勝負があります。
・ゲームとクイズはブラウザー表示領域いっぱいの画面を維持。長文と長い選択肢を読みやすく調整。
・コースやテーマの途中経過は再読み込みでリセットされます。ゲーム内の記録は診療記録等とは独立しています。
