今回の修正：ver1.13で表紙の起動が止まる問題

・新しい表紙に存在しない旧グリッドへ部品を追加する処理が残り、画面表示中に例外が発生していました。その処理を削除しました。
・起動中の全ての例外を「保存領域を開けません」と表示していた処理を修正。保存接続、読み込み、形式確認、画面表示を区別し、実際のエラーを表示します。
・AndroidにもSafariを案内する誤った共通文言を削除しました。
・通信量計測等の補助処理の失敗だけでは、起動済みの画面を止めないようにしました。
・説明ボタンの幅を確保し、言語欄との文字の重なりを修正しました。
・記録の削除、保存領域の変更、初期化は行っていません。

更新方法
・このZIPを全て展開し、github-pagesの中身一式を、現在のひめころさん版の同じ公開先へ更新してください。
・ブラウザーを読み直し、ver1.14を確認します。
・ブラウザーのデータやサイトの記録は削除しないでください。
・エラーが続く場合は「エラーの詳細」が読める画面をお知らせください。
