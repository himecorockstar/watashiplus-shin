ふわナース ひめころさん版 ver1.09
2026年10月31日

今回まとめて実施した変更
1. 最下部の青いNを削除し、先輩提供のBudo Companyロゴを画面幅いっぱいに表示。
2. 手鏡はブラウザーの表示領域全体に拡大。可能な環境では全画面表示も試みます。終了ボタンを常時表示。
3. 痛みは新規入力を0～5へ変更。旧0～10は自動換算せず、尺度を明記して保持。
   旧記録の編集時は「旧記録をそのまま残す」を初期選択。新しい0～5の値を選んで保存した場合だけ、その記録の尺度を変更。
4. ボイスアラームの「予定名・メモの見出し」を削除。「メモ」は「読み上げる内容」に改称。
   選択文は本文へ追記。自由に書き足せます。時刻には本文を順番に続けて1回読み上げます（繰り返し再生ではありません）。
   古いアラームは見出しと本文を合わせて編集欄へ表示し、保存までは元のデータを保ちます。
   録音がある場合は録音の声、ブザー・ベルを選んだ場合はその音を使います。
   本文を編集すると文字読み上げに戻り、以前の録音は解除されます。入力後の自動保存を確認してください。
5. 飲酒記録「LAST CALL」を追加。外部画像認識・有料の商品検索は使いません。
   種別→メーカー→商品名→度数→容量→本数を選択し、飲んだ分を加算。
   容量が1種類の場合は容量選択を省略。1缶あたりの容量と飲み干した本数で計算します。
   ウイスキーなどは原酒の量をcc入力可能。1cc＝1ml。
   大きな「飲み始め」「飲み終わり」で1回分を区切ります。途中で画面を閉じても保存済みの記録は残ります。
   個別取り消し、以前の飲酒の追記、月別・酒類別の合計、日別折れ線グラフを用意。
   未登録日は「記録なし」。時間経過によるアルコール分解や体内残量は計算しません。
   写真の読み取りや保存は行いません。写真方式から選択・手入力方式への最終指示を採用。
6. 商品追加は手入力が基本。メーカー・商品名の登録済み候補、度数・容量のボタンを使えます。
   同じ種別・メーカー・商品名はまとめ、異なる容量・度数を追加します。
   初期商品はビール10商品・缶チューハイ10商品。最新に閲覧できた飲用調査と販売店売れ筋掲載を参考に選定。
   全国売上上位10商品・2026年9月の確定順位とは表示しません。出典と対象期間はLAST_CALL_SOURCES.htmlを参照。
7. 葡萄モチーフのオリジナル容器6種類。架空メーカー名「ブドウ糖ビール」、ラベルに「LAST CALL」。
   実在商品のパッケージではない仮画像として、実際の商品名・メーカー・度数・容量と区別して表示します。

記録を守るために
・ver1.07・1.08と同じ端末内保存領域を維持。飲酒記録と商品一覧もバックアップ対象です。
・更新時にブラウザーのデータを削除しないでください。
・別のGitHubアカウントや別ホストでは記録は自動では移りません。旧版のバックアップを書き出し、新しい場所で読み込んでください。
・バックアップの読み込みは現在の記録を置き換えます。先に現在のバックアップも保存してください。
・旧0～10の痛み、旧録音日時、以前の日記・写真を勝手に削除しません。
・写真のクラウド選択、統合した「体調と測定データ」、秒単位の録音日時、自然音12種などは継承。

初めて使うLAST CALL
1. 表紙の「すべての機能を開く」から「LAST CALL・飲酒記録」を押します。
2. 飲む前に「飲み始め」を押します。
3. 飲み干した缶の商品・度数・容量を選び、本数を確認して「このお酒を飲んだ分に加える」を押します。
4. 原酒の場合は「量をccで入力する」から、割る前の量・度数を登録します。
5. 飲み終えたら「飲み終わり」を押すと、今回の合計が残ります。
6. 月を選ぶと酒類別合計と日別グラフが見られます。
7. 登録に間違いがあったら、その1件の「取り消す」を押して登録し直します。

・JavaScript構文、簡易DOMを使う初期化とイベント処理、商品20件、単一容量の選択省略。
・350ml・7％を10本＝3500ml・純アルコール196g。40％の原酒60cc＝19.2g。
・開始の二重登録防止、飲み終わり、取消、商品重複の統合、無効入力の拒否、保存失敗時の処理。
・日本時間で月をまたぐ記録、酒類別集計、折れ線グラフと日別数値の生成。
・新旧痛み尺度の選択欄、旧値の保持、新しい値の保存処理。
・本文への選択文追記、本文保存、長文を順番に読み上げる処理（疑似音声装置）。
・文字なしの録音メモと秒単位の日時保持、飲酒記録を含むバックアップ検証。
・ZIP破損検査、公開ファイル参照、実行JS一致、音源12件。

未確認・制限
・検証用ブラウザーが利用できないため、実際の画面操作とスマホの実機確認は未実施です。
・Android/iPhoneの鏡の実表示、マイクの実音録音、長文の実際の読み上げ、ブザー・ベルの聞こえ方、クラウド写真選択は実機で確認してください。
・OSの操作バーを消せるかは端末とブラウザーに依存します。カメラの利用許可が必要です。
・画面ロック中、別アプリ使用中、ブラウザー終了中の確実なアラームは保証できません。重要な予定はスマホ本体のアラームも併用してください。
・画像の銘柄・味・糖質・原材料を示すものではありません。選択値は手元の容器を確認してください。
・純アルコール量は入力した値に基づく計算値です。飲酒運転の可否、酔い、体内残量、安全な飲酒量を判定するものではありません。

公開手順
1. ZIPをダウンロードし、右クリック「すべて展開」を選びます。
2. github-pagesフォルダーを開きます。
3. ひめころさん版のGitHubで「Add file（ファイルを追加）」→「Upload files（アップロード）」を開きます。
4. github-pagesフォルダーの「中身」を全部アップロードします。フォルダーそのものではありません。
5. 「Commit changes（変更を保存）」を押し、公開後にサイトを再読み込みして最下部のver1.09を確認します。
・秦さん版の公開先へはアップロードしないでください。
・既存のGitHub Pages設定は維持してください。新規公開先ではPagesの有効化が必要です。
・旧版のJSがリポジトリに残っていても、index.htmlはapp-v1.09.jsを読みます。利用者の記録を消して更新しないでください。
