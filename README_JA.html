Watashi Plus・秦さん版 ver1.03

健康記録、写真日記、自然音、短いゲームを一つにまとめた、自分のための道具です。看板の上には贈り先のお名前を入れています。

試すには

watashiplus-hata.htmlをダウンロードしてブラウザーで開きます。音源入り・解凍不要です。スマホに贈る最終版はGitHub PagesのURLから開く方法を使います。公開前のため、この配布物自体は公開URLではありません。

ver1.03の変更

測定は＋／−の長押しで連続変更。最後に保存した値を初期表示します。薬は朝食後などの時間ごとにまとめて記録し、残量は小数と単位で入力できます。写真表示中は「写真立てを終了」を押します。自然音はアプリを開いて通信できるときに自動保存します。英文クイズは秦さん版から外しました。

基本操作

  • 黄色のTOPは表紙へ。「戻る」は一つ前の画面へ戻ります。入力途中は破棄前に確認します。
  • 「? 説明OFF」を押して説明ONにし、項目を３秒長押しすると説明が開きます。
  • 看板を１秒長押しすると手鏡。鏡は２秒長押し、または戻る・TOPで閉じます。カメラ許可が必要です。
  • 日記帳に文章や写真を残し、検索できます。測定値とグラフ、女性用の月間表、薬の７日間の履歴も使えます。女性用の不要な項目は設定で非表示にできます。
  • 写真立てはご自分で３枚まで登録します。電話帳は30件。名前を２秒長押しで編集、横スライドで発信確認に進みます。
  • 音で感じる季節は12種類、各60秒。保存済み12/12になれば、音源の再取得は不要です。模様だけ停止することもできます。

機種変更

「機種変更の準備」で記録と保存済みの音源をまとめて保存します。保存したものを新端末へ移し、「前のスマホの記録を取り込む」で読み込みます。お店の方向けの説明もあります。

写真や記録は端末内のブラウザーに保存します。削除・故障に備え、定期的に記録を保存してください。新しいスマホで確認できるまで古いデータは消さないでください。予定の音声通知は画面を開いて使う補助機能です。医療判断や緊急通報の代わりにはなりません。

公開する方へ

ZIPのgithub-pages内の全ファイルとaudioフォルダーをGitHub Pagesの公開対象へ置きます。index.htmlとapp.jsなどの位置関係を保ってください。日記などの個人記録は公開ファイルには含めません。音源の出典はAUDIO_CREDITS.txtを参照してください。
