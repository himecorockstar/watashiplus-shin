写真について
同梱４枚は先輩から提供された画像を縮小したものです。人物の加工はしていません。
GitHub Pagesへこの一式を公開すると、同梱写真も閲覧できる状態になります。今回は公開していません。

使い方
１．「ひと息・遊び」→「写真立て」を開きます。
２．各枠の「写真を選ぶ」から10枚まで登録できます。クラウド選択も従来どおり使えます。
３．「自動切替」にチェックを入れ、「写真立てを開く」を押します。
４．写真立ての中のオン・オフでも切替を停止・再開できます。「戻る」で終了します。
５．「音で感じる季節」では、光粒が流れます。好きな季節の音を選べます。
