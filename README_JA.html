今回の変更
１．常識クイズを６分野・各50問、計300問に入れ替えました。
ペット／料理／運動／スマホ／配信／家電。
各分野50問のランダム順で、一巡までは重複しません。
答えを開く自己確認式33問、二択17問。答え本文は全問30文字以内で、解説は別に開けます。
前の問題へ戻っても回答の状態を保持します。時間制限はありません。
問題はこのアプリ向けに独自作成しました。参考にした公式資料はクイズ入口の「問題について・参考資料」から確認できます。

２．ゲームを、なじみのある札・牌と短時間の遊びを中心にした50種類へ入れ替えました。
トランプ10、花札６、麻雀牌10、色あそび８、数字あそび６、おなじみ10。
花札・麻雀牌は、題材を使った短いミニゲームです。通常のこいこいや４人麻雀そのものではありません。
１分くらいは目安です。時間で打ち切りません。新しい配置、やり直し、一手戻る、戻した手を進める、ヒント、盤面を変えない操作例を使えます。
ハイ＆ロー・じゃんけん・対戦の操作例は、勝ちを保証するものではありません。
ゲームの途中経過は生活記録として保存しません。ページを閉じたり再読み込みしたりすると最初からになります。

３．写真立てを左右のスクロールで前後へ動かせるようにしました。
前後ボタン、キーボードの左右矢印でも切り替えられます。
５秒ごとのランダム自動切替も維持し、写真立てを閉じると停止します。
写真を選ぶ場所は最上部の「ファイル・クラウドから写真を選ぶ」１か所です。
複数選択は空き枠へ追加します。差し替えは、対象枠の「この写真を選び直す」を押してから共通の選択欄を使います。
空き枠を超える枚数は、途中まで勝手に保存せず選び直しを案内します。
前後ボタンは薄い金色の背景と濃い文字に固定し、白抜けを防ぐ表示に変更しました。

継続する機能
四季の光粒、写真10枚と初期写真４枚、飲酒記録LAST CALL、日記、体調と測定データ、女性用の記録、服薬記録、音声メモ・アラームなどは維持しています。
保存先のデータベース名・形式を継続し、既存の生活記録を消したり移し替えたりしません。

写真について
提供された４枚の初期写真を同梱しています。既存の登録写真は上書きしません。
この一式を一般公開すると、同梱写真も閲覧できる状態になります。

300問の件数・重複・解答長、出題・回答・前後移動、各ゲームの画面・戻す操作・操作例、写真の保存・横スクロールの処理を確認しました。
ブラウザーのプレビューでクイズ、七並べミニ、写真の前後・横スクロール、ボタンの色を確認しました。

アラームは画面表示中の補助機能で、ロック中の確実な通知はできません。

素材について
新しい問題文・解説、札や牌の文字図柄、ゲーム処理は独自作成です。外部の無料ゲームコードや既存問題集の転載はしていません。
端末によって絵文字の図柄は異なります。
音源の条件はgithub-pages/AUDIO_CREDITS.txt、飲酒データの説明はLAST_CALL_SOURCES.htmlを参照してください。
